# tizen-home-screen

A fast custom home screen for a Samsung Tizen TV (2020, Tizen 5.5): a single-page web app that replaces the stock launcher with a 1920×1080 grid of streaming apps and inputs. A browser preview (`npm run preview`) lets you iterate on the UI without the TV, and `just tv-install` builds and installs the package onto the set.

The TV-side Home-button takeover is deliberately out of scope.

## Design

Layout and visual style are adapted from [arn0-tv](https://github.com/NelsonEU/arn0-tv) (MIT) by Arnaud Etienne. The Manrope font (SIL OFL 1.1, licence in `ui/fonts/OFL.txt`) is vendored from the same project.
